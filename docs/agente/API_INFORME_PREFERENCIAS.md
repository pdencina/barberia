# API de preferencias del informe — pieza 3

**HECHO:** la ruta compone `requireRole(["admin", "super_admin"])` con el manejador probado (`src/app/api/agente/informe-preferencias/route.ts:8-13`). Ese guard obtiene identidad/negocio de sesión y rechaza falta de sesión/rol (`src/lib/supabase/server.ts:239-249`). Se eligió este guard y comprobación propia de dueño/tenant porque el permiso general `isManagerLevel` incluye recepción (`src/lib/supabase/server.ts:106-109`), que no puede editar estas preferencias.

**HECHO — contrato del manejador:** `src/lib/agente/informe-preferencias.ts:44` compone GET/PUT. Admin llama sin parámetros de selección: profile_id y tenant_id salen del guard, no del cuerpo. Cualquier selección por query se rechaza para admin, incluso si repite sus IDs. Super_admin debe indicar ambos `?profileId=<uuid>&tenantId=<uuid>` de negocio concreto; ALL se rechaza. Antes de acceder a la preferencia se consulta el perfil con ambos filtros y se exige admin activo de ese negocio. No se lee ni devuelve correo.

**HECHO — GET:** devuelve `{ preference: { profile_id, tenant_id, enabled, frequency, custom_weekdays, weekly_weekday, anchor_date, send_local_time, effective_from, revision } }`. Si no hay fila, devuelve valores apagados, hora/vigencia nulas y revisión nula sin escribir. Migración faltante: 503, `{ error: "Falta aplicar la migración", enabled: false }`. Respuestas sin caché.

**HECHO — PUT:** solo admite los siete campos de configuración del whitelist (`src/lib/agente/informe-preferencias.ts:10-12`). Rechaza JSON malformado, objeto vacío, campos extra, correo/identidad/revisión/timestamps y valores inválidos. Admite cambios parciales sobre la fila actual; para activar exige vigencia y hora explícitas, más ancla/día(s) según frecuencia. No asigna una hora ni reinicia el ancla silenciosamente. Al cambiar a no semanal/no personalizada, el llamador debe limpiar sus campos incompatibles explícitamente. Actualización con revisión esperada y filtros de perfil/tenant; conflicto devuelve 409 para recargar. Origen cruzado rechazado antes de consultar base.
